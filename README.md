# HEALTHCARE-DASHBOARD
HEALTHCARE DASBOARD POWER BI

This Healthcare Dashboard is an interactive Power BI project designed to analyze and visualize healthcare-related data for better decision-making. The dashboard provides insights into patient records, treatment performance, hospital operations, and healthcare trends through dynamic visualizations and KPI tracking.

The project focuses on transforming raw healthcare data into meaningful insights using Power BI features such as data modeling, DAX calculations, slicers, filters, and interactive charts.

Key Features
Interactive and user-friendly dashboard design
Real-time healthcare data visualization
KPI tracking for healthcare performance analysis
Patient and treatment data insights
Department-wise and category-wise analysis
Dynamic filters and slicers for better exploration
Clean and professional dashboard layout
